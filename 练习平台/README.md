# S7-200 SMART 认证练习平台

**双击 `index.html` 即可使用**（推荐 Edge / Chrome），完全离线运行，无需安装任何东西。

## 功能

| 模块 | 说明 |
|---|---|
| 📚 分类练习 | 10 大主题 344 题（硬件选型 / IO / 寻址 / 指令 / 高速计数 / 运动 / PID / 串口 / 以太网 / HMI维护），逐题即时判分 + 解析 + 资料出处 |
| 🎲 随机练习 | 自选数量随机抽题 |
| 📝 真题模拟 | A~E 五套原卷（每套70题），考试模式计时、答题卡、交卷判分 |
| 🧪 智能组卷 | 从题库随机组卷（50题快练 / 70题全真） |
| ❌ 错题本 | 答错自动收录，重练消灭，答对自动移除 |
| ⭐ 收藏夹 | 做题时点 ☆ 收藏重点题 |
| 🔎 搜题 | 关键词搜题干和选项 |
| 📈 统计 | 累计做题数、总正确率、各主题正确率 |

## 使用说明

- **做题**：单选题点选项立即判分；多选题选完后点「提交答案」；键盘 `1~5` 选答案、`←/→` 翻页
- **数据**：进度、错题、收藏保存在浏览器本地（localStorage），换浏览器/清缓存会丢失
- **主题**：右上角 🌓 切换深色模式；A⁻/A⁺ 调整字号
- **图片题**：题目配图（梯形图等）点击可放大
- 真题卷答案由 AI 依据官方资料（系统手册 v2.8 / 技术参考 PLUS 2.6 / 选型手册 v2.8）整理，标注了置信度；低置信度的题不计入判分

## 数据更新

题库或答案更新后，在项目根目录运行：

```
.venv/Scripts/python.exe build_platform.py
```

重新生成 `data.js`（数据源：`考试模拟卷/题库.json` + `题库资料/papers_raw.json` + `题库资料/answers/*.jsonl`）。
