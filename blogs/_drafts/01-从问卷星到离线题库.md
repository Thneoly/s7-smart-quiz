# 从问卷星到离线题库：一次 PLC 认证备考资料的自动化整理

> 原始需求很简单：把 5 套挂在问卷星上的《S7-200 SMART 认证模拟卷》整理下来。最后做成了一个双击即用的离线刷题平台。这篇记录中间的每一步坑。

## 一、需求与第一反应

5 个链接，形如 `https://ks.wjx.com/vm/wEOMMqS.aspx`。需求是"整理下来"。

第一反应是 `curl` 拉 HTML 解析。拉下来 204KB，看起来很有希望——直到发现 HTML 里 `div_question` 计数为 0：**问卷星移动版的题目是 JS 动态渲染的**，静态 HTML 里只有骨架和 `jqnonce`、`activityId` 这些变量。

改走渲染路线。普通渲染工具（webkit 内核的在线转 markdown 服务）能拿到题干，但**丢掉了大部分选项**——只有个别题的选项在渲染结果里。原因后面才明白：选项加载有时序，渲染快照的时机不稳定。

## 二、无头浏览器 + 系统 Edge

真正可靠的做法是本地无头浏览器。Python + Playwright：

```python
browser = p.chromium.launch(channel='msedge', headless=True)  # 复用系统 Edge，无需下载 chromium
```

一个小细节省了大量时间：**Windows 上不必 `playwright install chromium`**（国内网络下载 chromium 超时过一次，换 npmmirror 镜像才拉下来），直接 `channel='msedge'` 用系统自带的 Edge 就行。Win10/11 必有 Edge，WebView2 也随之而来——这个判断后面做桌面端时再次救了我。

页面渲染后 DOM 结构非常清晰：

```html
<div class="field" type="3">          <!-- 3=单选 4=多选 1=填写 -->
  <div class="topichtml">题干…</div>
  <div class="ui-radio">
    <div class="label">A、3</div>
```

5 套卷子共 **350 道选择题 + 11 张配图**，全部完整提取。

## 三、图片防盗链：403

题目配图（梯形图截图）托管在 `pubnewfr.paperol.cn`，直接 `urllib` 下载全部 403。这是典型的 Referer 防盗链：

```python
HDRS = {
    'User-Agent': 'Mozilla/5.0 …',
    'Referer': 'https://ks.wjx.com/',   # 加这一行，11 张图全部下载成功
}
```

下载后把 Markdown 里的远程链接改写为本地相对路径 `images/xxx.png`，卷子就完全离线可用了。

## 四、从"卷子"到"平台"

整理完卷子只是开始。接下来把官方文档变成**带答案的题库**（另一个故事），然后做了一个单文件 HTML 的离线练习平台：

- 纯原生 JS，零依赖，`data.js` 存题库数据（`<script src>` 从 `file://` 加载没问题；**`fetch()` 在 file:// 下会被 CORS 拦**，这是选 data.js 不选 json 的原因）
- 分类练习 / 真题模拟 / 错题本 / 收藏 / 搜索，localStorage 持久化
- 用 Playwright 写了 11 项自动化测试。调试中发现一个真 bug：**做了一半的题目退出时，草稿靠 1.5s 防抖保存——退出时还没触发**。修复：退出按钮改为强制落盘。这类时序 bug 肉眼几乎测不出来，自动化测试的价值就在这

## 五、几个可复用的结论

1. **动态页面抓取的标准姿势**：无头浏览器 + 等 `div.field` 这类业务元素出现 + 滚动到底触发懒加载，比分析 AJAX 接口逆向参数稳定得多
2. Windows 上 Playwright 用 `channel='msedge'`，零下载成本
3. 防盗链 403 先想 Referer；图片本地化让产物真正离线
4. `file://` 场景下静态数据用 `<script src="data.js">` 而不是 fetch JSON
5. 有交互的页面产物，**自动化测试（Playwright）应该在第一天就写**——它抓出的草稿丢失、答题卡状态这类 bug，手动回归根本覆盖不全

最终产物：5 套卷 350 题（含 AI 依据官方资料整理的参考答案）、344 题知识点题库、一个双击即用的练习平台。而这只是后面 Tauri 桌面应用版的故事的开头。
