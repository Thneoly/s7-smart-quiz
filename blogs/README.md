## 各篇一句话

1. **可信是流水线做出来的，不是一次生成出来的**——出处字段、上下文隔离、证据要求，缺一个都不可信
2. **Tauri 适合本地优先小工具，成败在"文档不主动告诉你"的那五个问题**
3. **AI 最好的用法之一：用一个没有沉没成本偏见的实例，攻击你刚写完的东西**
4. **每一步扩张都有触发条件，但架构从第一天就为扩张留门**
