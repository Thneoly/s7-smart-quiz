## 分支与提交约定

- **main**：可用状态，每次提交保证 cargo 11 项 + E2E 47 项全绿
- 功能开发：`feat/xxx` 分支，完成后合回 main
- **标签**：`v0.1.0`（当前）——与 tauri.conf.json 的 version 对应，发布时同步递增
- 提交信息：中文，格式 `类型: 摘要`（feat/fix/docs/test/chore）
- 签名密钥 `~/.tauri/smartquiz.key` **永不入库**，备份到密码管理器/离线盘

## 远程仓库（私有）

内容含西门子版权文档的提取文本与 AI 整理答案，**仓库保持私有**（勿改公开）：

```bash
# GitHub 私有仓库（已建）
gh repo create s7-smart-quiz --private --source . --push
git push --tags
# 或 Gitee 镜像（国内访问快）
git remote add gitee git@gitee.com:<你的用户名>/s7-smart-quiz.git
git push -u gitee main --tags
```

## 数据流水线（改动数据时的重跑顺序）

```
改题库题目/答案 (题库资料/questions、answers)
  → scripts/21_apply_corrections.py（如有校验修正）
  → scripts/20_merge_bank.py    → 考试模拟卷/题库.md + 题库.json
  → scripts/30_pack_seed.py     → smart-quiz-app/src-tauri/resources/seed/*.smartbank
改资料语料 → scripts/32_pack_docs.py → resources/docs/docs.docpack
改指南    → scripts/40_gen_guide.py（数据在 题库资料/guide_stages.json）

之后统一：cd smart-quiz-app && npm run build && 回归 tests/e2e_*.py
```

## 日志与排障（v0.2 可维护性）

| 项 | 说明 |
|---|---|
| 位置 | `%LOCALAPPDATA%\com.smartquiz.app\logs\`（应用内：设置 → 运行日志 → 打开日志目录） |
| 轮转 | 每次启动新文件；保留最近 3 次；单文件超 2MB 再轮转；总量上限约 8MB |
| 级别 | Debug：`INFO`=生命周期（启动/种子导入/会话开始完成/Excel导入/索引构建/诊断导出），`DEBUG`=命令名+耗时，`ERROR`=命令失败/panic |
| 高频降级 | save_draft / note_get / note_set / fav_toggle / setting_* 成功只记 trace（不落盘） |
| panic | 全局钩子捕获，带 backtrace 落 `ERROR`（release 也可定位） |
| 前端 | Vue errorHandler / window error / unhandledrejection → 经 plugin-log 同一文件 |
| 隐私 | 只记命令名/耗时/错误串/数量，**绝不记题目内容与用户输入**（会话标题/题库名均不记）；搜索词只记长度；路径脱敏隐藏账户名 |
| 诊断包 | 设置 → 导出诊断包自动附带全部日志文件（可放心外发） |

排障思路：用户报问题时，拿到诊断包 → 看 `logs/` 里最后一次启动的 `INFO` 时间线定位到命令 → 对应 `ERROR` 行有错误串与耗时 → 结合 `diagnostics.json` 的版本/数量判断回归范围。

## 发布 checklist（每次发版）

1. cargo test + 全部 e2e 通过
2. `src-tauri/Cargo.toml` version 递增（单一版本来源，`tauri.conf.json` 不携带 version）+ git tag
3. `TAURI_SIGNING_PRIVATE_KEY` 前台环境变量下 `npm run tauri build`
4. 确认产物含 `*-setup.exe` **与 `.sig`**
5. `make_update_manifest.py <版本> <说明> <URL前缀>` → 上传 setup.exe + latest.json
6. （签名证书就绪后）Authenticode 签名 + SmartScreen 验证
7. 安装后冒烟：设置 → 查看最近日志有本启动记录，二次重启确认轮转命名（`*_时间.log`）
