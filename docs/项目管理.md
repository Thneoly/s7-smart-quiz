
## 已忽略的可再生内容 → 再生方法

| 忽略项 | 再生命令 |
|---|---|
| `题库资料/techref26/`（技术参考反编译） | `hh.exe -decompile <输出目录> <原始CHM路径>`（CHM 在学习资料目录；**中文带括号路径会静默失败，先复制到 ASCII 路径**） |
| `题库资料/microwin/`（MicroWIN帮助反编译） | 同上 |
| `题库资料/techref.txt` 等提取文本 | `html2txt.py`（在 /tmp，逻辑见提交历史）→ 实际以 `题库资料/*_txt/` 已入库版本为准 |
| `docs.docpack` / `.smartbank` | 实际上**已入库**（构建必需，1.8MB）；重新生成用 `pack_docs.py` / `pack_seed.py` |
| `shots/` 测试截图 | 跑各 `tests/e2e_*.py` 自动生成 |

## 分支与提交约定

- **main**：可用状态，每次提交保证 cargo 11 项 + E2E 47 项全绿
- 功能开发：`feat/xxx` 分支，完成后合回 main
- **标签**：`v0.1.0`（当前）——与 tauri.conf.json 的 version 对应，发布时同步递增
- 提交信息：中文，格式 `类型: 摘要`（feat/fix/docs/test/chore）
- 签名密钥 `~/.tauri/smartquiz.key` **永不入库**，备份到密码管理器/离线盘

## 远程仓库（建议私有）

内容含西门子版权文档的提取文本与 AI 整理答案，**建议私有仓库**：

```bash
# GitHub 私有仓库
gh repo create smart-quiz --private --source . --push
# 或 Gitee（国内访问快）
git remote add origin git@gitee.com:<你的用户名>/smart-quiz.git
git push -u origin main --tags
```

## 数据流水线（改动数据时的重跑顺序）

```
改题库题目/答案 (题库资料/questions、answers)
  → scripts/21_apply_corrections.py（如有校验修正）
  → scripts/20_merge_bank.py    → 考试模拟卷/题库.md + 题库.json
  → scripts/30_pack_seed.py     → smart-quiz-app/src-tauri/resources/seed/*.smartbank
  → scripts/31_build_platform.py→ 练习平台/data.js
改资料语料 → scripts/32_pack_docs.py → resources/docs/docs.docpack
改指南    → scripts/40_gen_guide.py（数据在 题库资料/guide_stages.json）
改速查    → scripts/41_gen_refdata.py（数据源为多智能体工作流 journal，一次性）
抓取更新  → scripts/10_scrape_papers.py + 11_fix_images.py + 12_parse_papers.py
之后统一：cd smart-quiz-app && npm run build && 回归 tests/e2e_*.py
```

## 发布 checklist（每次发版）

1. cargo test + 全部 e2e 通过
2. `tauri.conf.json` version 递增 + git tag
3. `TAURI_SIGNING_PRIVATE_KEY` 前台环境变量下 `npm run tauri build`
4. 确认产物含 `*-setup.exe` **与 `.sig`**
5. `make_update_manifest.py <版本> <说明> <URL前缀>` → 上传 setup.exe + latest.json
6. （签名证书就绪后）Authenticode 签名 + SmartScreen 验证
